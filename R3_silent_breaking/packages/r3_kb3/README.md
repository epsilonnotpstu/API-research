# Source packages

items.csv lists each item, repository, language, and source paths. Each item has item.md and diff.patch, complete source versions under before/ and after/, and checked-in API documents under contract/ when available. Repository paths are preserved. API documents may contain selected operations and their local references or a bounded selection in path order. Source values may be replaced with [REDACTED]. JSON-formatted contract files are also valid YAML 1.2. TASK_R3.md contains the reading instructions.
