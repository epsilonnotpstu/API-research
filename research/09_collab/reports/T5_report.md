- `prepare_dist.sh scout-api`: supervisor-built jar-এর নির্দিষ্ট source path থেকে EMB `dist/` layout তৈরি করার script; content অপরিবর্তিত হলে SUT jar পুনরায় copy করে না। JaCoCo **0.8.12 runtime agent** ও একই version-এর **nodeps CLI** Maven Central-এর HTTPS URL থেকে নিয়ে `.sha1` মেলায়; mismatch হলে install করে না। CLI অতিরিক্ত artifact, কারণ JVM বন্ধ করার আগে TCP-server থেকে coverage dump দরকার (`08_experiments/E1_pilot/harness/prepare_dist.sh:8-46`; `08_experiments/_external/emb/dockerfiles/scout-api.dockerfile:22`; [JaCoCo dump](https://www.jacoco.org/jacoco/trunk/doc/cli.html))।
- Compose override-এ explicit EMB build context, host UID/GID, per-run log mount, local tools directory থেকে logger mount এবং `-s /addons/mitm_fulllog.py` দেওয়া হয়েছে। Base compose-এর same-target mounts override করার উদ্দেশ্য; actual merge T7-তে saved resolved configuration দেখে যাচাই করতে হবে (`08_experiments/E1_pilot/harness/compose.override.scout-api.yaml:1-29`; `08_experiments/E1_pilot/harness/run_pilot.sh:98`)।
- `run_pilot.sh` baseline/mutated parameter যাচাই, unique run directory/Compose project, sequential lock, mutation CLI ও manifest copy, pinned `schemathesis/schemathesis:3.39.16`, `--checks all`, fixed seed, per-operation example limit ও wall-time timeout নির্ধারণ করে। Readiness exchange আলাদা করে; EXIT/INT/TERM cleanup-এ generator সরিয়ে JVM জীবিত থাকতেই coverage dump, তারপর project teardown করে (`08_experiments/E1_pilot/harness/run_pilot.sh:5-43,55-81,86-159`)।
- `run_metadata.py` atomic `run.json` লেখে: সাতটি argument, run ID, effective configuration, timestamps/status, EMB commit/dirty status, jar/tool/harness/artifact SHA-256, image ID এবং উপলব্ধ registry digest। Local build-এর registry digest অনুপস্থিত হলে সেটি খালি রাখে, বানিয়ে দেয় না (`08_experiments/E1_pilot/harness/run_metadata.py:15-59`)।
- `analyse_run.sh` complete baseline/mutated pair-এর provenance ও artifact hash যাচাই করে। Fresh comparison-এ আলাদা traffic ব্যবহার করে `attribute.py --mode fresh`; replay-তে **একই baseline exchanges** original ও mutated spec দিয়ে check করে `--mode replay` চালায়। Default `both`; output directory overwrite করে না। T10-এর CLI অপরিহার্য (`08_experiments/E1_pilot/harness/analyse_run.sh:5-58`; `09_collab/tasks/T5.md:17-18`)।
- README-তে baseline seed **1,2,3**, এরপর চারটি fault class-এর severity **30%**, seed **1**—সবগুলির exact Bash sequence দেওয়া হয়েছে। প্রতি condition-এ default maximum **100 examples/operation**, generation budget **600 seconds**; budget expiry হলে partial run nonzero exit এবং automatic analysis প্রত্যাখ্যান করবে (`08_experiments/E1_pilot/harness/README.md:20-62,88-96`; `08_experiments/E1_pilot/harness/analyse_run.sh:14-15`)।

## Assumptions, সীমাবদ্ধতা ও ঝুঁকি

1. **Health:** ⚠️ `/admin/healthcheck` অনুমিত endpoint, runtime verified নয়। Simple server config-এ application `/api`, admin `/admin`, port 8080; application health check register করে। T7-তে route ও response verify করতে হবে (`08_experiments/_external/emb/scripts/dockerize/data/additional_files/scout-api/scout_api_evomaster.yml:1-10`; `08_experiments/_external/emb/jdk_8_maven/cs/rest/original/scout-api/api/src/main/java/se/devscout/scoutapi/ScoutAPIApplication.java:146-147`; `08_experiments/E1_pilot/harness/README.md:122-126`)।
2. **Base path:** `/api` source spec/config-এ ঘোষিত; ⚠️ Schemathesis v3 `--base-url` এবং proxy দিয়ে আসল captured path-এ prefix একবারই আছে কি না T7-তে দেখতে হবে (`08_experiments/_external/emb/openapi-swagger/scout-api.json:11`; `08_experiments/E1_pilot/harness/README.md:127-129`)।
3. **Auth:** “auth নেই” কথাটি runtime coverage-এর জন্য প্রতিষ্ঠিত নয়: application auth filters register করে, authenticator-এর prefix `ApiKey`, config seeded identities দেয়। ⚠️ Unauthenticated run protected operation-এ সীমাবদ্ধ হতে পারে। বর্তমান harness auth assumption metadata-তে রাখে; auth-enabled experiment হলে controls-সহ নতুন documented batch দরকার (`08_experiments/_external/emb/jdk_8_maven/cs/rest/original/scout-api/api/src/main/java/se/devscout/scoutapi/ScoutAPIApplication.java:186-203`; `08_experiments/_external/emb/jdk_8_maven/cs/rest/original/scout-api/auth/src/main/java/se/devscout/scoutapi/auth/apikey/ApiKeyAuthenticator.java:17`; `08_experiments/_external/emb/scripts/dockerize/data/additional_files/scout-api/scout_api_evomaster.yml:50-65`; `08_experiments/E1_pilot/harness/run_metadata.py:43`)।
4. **Attribution:** ⚠️ Fresh NEW/VANISHED causal proof নয়; replay কেবল checker/oracle change আলাদা করে, generation-side degradation মাপে না। Fixed seed identical traffic নিশ্চিত করে না (`09_collab/reports/T4_review.md:R03`; `08_experiments/E1_pilot/harness/README.md:144-155`)।
5. **Logger:** T10-এর ownership অক্ষুণ্ণ রেখে শুধু README-তে `error(flow)` hook + request/correlation/transport-error capture এবং coverage reconciliation-এর plan আছে; logger edit করা হয়নি। Runtime reset/timeout fixture T7-তে দরকার; response-only log-এ missing exchange-কে masking ধরা যাবে না (`09_collab/reports/T4_review.md:S03`; `09_collab/tasks/T5.md:18`; `08_experiments/E1_pilot/harness/README.md:137-143`)।
6. **Completeness:** budget expiry, missing exchanges, dump failure বা teardown failure-এ run incomplete। JUnit থাকলেও Schemathesis exit 1-এর assertions বনাম execution errors manual review করতে হবে। SIGKILL/host/daemon loss-এ cleanup নিশ্চিত নয় (`08_experiments/E1_pilot/harness/run_pilot.sh:55-81,153-159`; `08_experiments/E1_pilot/harness/README.md:88-118`)।
7. **Integration:** ⚠️ Docker image availability/entrypoint, host UID/GID permissions, exact Compose merge, Java-agent compatibility, TCP dump ও restart flushing পরীক্ষা বাকি। SHA-1 repository integrity check স্বাধীন authenticity signature নয় (`08_experiments/E1_pilot/harness/README.md:13-18,77-86,151-155`)।
