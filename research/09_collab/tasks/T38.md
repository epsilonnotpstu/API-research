# T38 — intent_evidence.py: bound git history to the source tree's own repository (Codex, direct edit)

Read `09_collab/PROTOCOL.md` first. Effort: medium.

## Why
In E5 blind v3, both labellers (D1, D2) ran `08_experiments/tools/intent_evidence.py` on a blind package's `K??/source`. That directory has no VCS of its own.

The tool's history probe (`git -C root rev-parse --is-inside-work-tree`, around `intent_evidence.py:810–845`) climbed to the enclosing **research** repository. It then ran `git log` there.
- Claude verified that no hit and no sensitive content came back, because the package paths are gitignored.
- But in a blind setting this is a leakage channel. It also reports `availability=available` for a tree that has no history.

## Requirements
1. **Git history must count as available only if the git toplevel lies at or inside `source_dir`.** In other words, `source_dir` itself, or a subdirectory of it, is the work tree root, as with the EMB sources under `_external`.
   - If the enclosing repository's toplevel lies **above** `source_dir`, treat history as `unavailable`, with reason `enclosing repository outside source_dir`, and run **no** `git log`.
   - Also pass `GIT_CEILING_DIRECTORIES` set to the parent of `source_dir`, as defence in depth.
   - ⚠️ First check how `root` is chosen today, and the `_external` EMB layout: is `source_dir` the repo root, or a subdirectory of it? Example: `_external/emb` is one git repo, and labelling passes `…/cs/rest/original/scout-api`.
     - Today's behaviour for that case, searching EMB history, is intended and must keep working.
     - So the rule is: allow the history search when the git toplevel is a **directory the caller explicitly opts into**. Recommended: a new CLI flag `--history-root DIR`, which must be an ancestor of or equal to `source_dir`. By default (no flag), history is allowed only if the toplevel is at or inside `source_dir`.
     - Document how the T36 / T33 invocations would need `--history-root` to keep their EMB history. Do not edit those reports.
2. Record `history.scope` = `own_repo` / `explicit_root` / `unavailable` in the JSON, plus `toplevel_inside_source` as a boolean.
3. **Tests (`tools/test_intent_evidence.py`):**
   - a temp repo whose toplevel is above `source_dir` → unavailable, and no `git log` subprocess is executed (mock or spy);
   - a temp repo whose toplevel = `source_dir` → available;
   - `--history-root` set to an ancestor → available, `explicit_root`;
   - `--history-root` that is not an ancestor → exit 2;
   - no git at all → unavailable.

   All existing tests must still pass.
4. **Report:** `09_collab/reports/T38_report.md` (Bengali; technical terms in English), plus one board Log line.
