# T37 — REQUEST_STRICT keyword ablation knob in specmut + harness_v2 (Codex, direct edit)

Read `09_collab/PROTOCOL.md` first. Effort: high.

## Why
T35 (`09_collab/reports/T35_report.md`) showed why EvoMaster's market REQUEST_STRICT signal is 0/3:
- The STRICT edit makes optional `_links` **required**, alongside `maxLength:1`.
- EvoMaster therefore always sends an array `_links`, which the SUT's HAL parser turns into a 500.
- Phone/address breaches were not the cause.

A multi-keyword STRICT edit therefore confounds a single-constraint reading.

**Supervisor-delegated decision (Claude, 2026-11-15):** run a keyword ablation of REQUEST_STRICT. For that we need a knob that keeps exactly the same operation selection and drops all edits except the chosen keyword family.
