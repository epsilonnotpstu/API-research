# T2 — Triage classifier prototype (roadmap E4)
Read first: `../PROTOCOL.md`, `../../08_experiments/R1_triage_codebook.md` (v0.2, esp. §2–§4, §8), `../../08_experiments/E2_labelling/README.md`, `../../08_experiments/E2_labelling/build_labelling_sheet.py` (current rule baseline, function `suggest`), `../../08_experiments/E1_pilot/P001_empirical_findings.md`.

## Goal
Implement `triage.py`: given one conformance failure with its evidence, output Level-1 label (SPEC/IMPL/BOTH/TEST/ENV/UNDECIDABLE), Level-2 code, confidence 1–3, and the list of evidence codes/rules used. It must be **strictly better-informed than the baseline** `suggest()` and reduce UNDECIDABLE on the P001 sheet (baseline: 36/73) **without** lowering precision on the 5 high-confidence double-escape cases.

## Evidence features to implement (each a separate, unit-tested function)
1. `strict_only` (given column) → codebook §8.1.
2. Unsatisfiable/broken pattern (double escape; Java-only regex) → §8.4.
3. **E-CONSIST across cluster/API:** using the raw rows in `../../08_experiments/_external/p001/faultClustersConfirmedBugs_<api>.csv` (columns `responseBody`, `failReason`, `path`, `statusCode`), check whether the violating JSON path / field behaves consistently across the API's other responses (e.g. field null in some, non-null in others → nullable omission §8.3; property present in all responses → undeclared but intentional §8.1/R2).
4. Format rules: date/date-time values that are valid in a common alternative format (e.g. `2021-11-03T00:00:00-0400` without colon offset) → spec format too narrow (SPEC lean, conf 1–2).
5. Undocumented 4xx on valid input (Marvel 400/404/409): if response body is a well-formed error object, documented elsewhere in the same spec for other operations → SPEC/S-STATUS (missing per-operation doc), else UNDECIDABLE.
6. ENUM/NUMERIC_RANGE: value outside enum but appearing repeatedly across responses → SPEC (enum incomplete), conf 1.
7. COMPOSITION: check satisfiability of the schema branch only if you can load the spec from `../../08_experiments/_external/p001/specs/` with `08_experiments/tools/conformance.py`/`specmut.py` helpers; otherwise UNDECIDABLE.
Never label IMPL without positive evidence (5xx, or request-side constraint documented). Explain every rule in a docstring citing the codebook section.
