## Requirements

### 1. Precise retrieval (new pool, `pool2`)
- **Contract path:** a file that, at the parent or the child, is an OpenAPI/Swagger document (top-level `openapi` or `swagger` key, or a file `$ref`-reached from one), **or** a JVM source file containing contract annotations (springdoc, springfox, swagger-core, JAX-RS `@Path` with OpenAPI annotations).
- **Behaviour path:** production source under the server modules (handlers, controllers, resources, routes, DTOs, models, validators, serializers, error mapping), in Java/Kotlin/Go.
- **Exclude:**
  - `.github/`, CI, helm, k8s, docker, compose, deploy, terraform and config-only YAML;
  - docs-site-only paths, unless they are the OpenAPI document;
  - test-only commits;
  - generated client SDKs.
- **Candidate condition and score: unchanged from T45.**
  - Condition: correction cue AND (contract path OR behaviour path).
  - Score: `10 × cue_strength + operation_path_bit`. No direction-specific bonus.
- **Exclude** every candidate already reviewed in T42, T43 or T45.
- Freeze `pool2` (hash in `freeze2.json`) before review. Report the pool2 size per repo.

### 2. Review (same acceptance gate as T42/T43/T45)
- Review pool2 in rank order per repo.
- **Per candidate, record:** `review_status`; one `reason_code` ∈ {ACCEPT, NOT_CONTRACT_RELATED, NEW_FEATURE_OR_ENDPOINT, REFACTOR_OR_RENAME, GENERATED_OR_DOCS_ONLY_CHURN, BOTH_CHANGED_TO_NEW_BEHAVIOUR, NO_PARENT_MISMATCH, TEST_OR_CLIENT_ONLY, TOO_LARGE_TO_ESTABLISH, OTHER}; and a ≤25-word reason specific to that candidate.
  - **No range-level reasons.**
- **Stopping rule:** stop when new accepted items (T45 + T46) reach ≥45 in total, or when every repo has had its top 60 pool2 candidates reviewed.
  - **Per-repo cap:** 6 new items, counting T45's items.
- **Dedup:** against `combined_accepted.csv` and the T45 accepted set.
- **Do not target or balance directions.**
