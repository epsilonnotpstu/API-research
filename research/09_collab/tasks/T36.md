## Goal
Apply §11.4 (search → review → label) to a pre-specified sample of **baseline** items. The aim is to measure:
- feasibility: time/effort per item, coverage gaps, how often the tool misses;
- reporting quality: every §11.4.4 field filled with valid locators;
- how often the procedure would change an existing final label.

This is NOT an accuracy benchmark. The final labels are adjudicated, not ground truth (`E2_labelling/FINAL_LABELS.md`).

## Sample (pre-specified — do this FIRST, before any search)
- **Population:** `08_experiments/E2_labelling/final_labels_baseline_s1.csv` (161 items).
- **Exclusions:** B065, M003, M005, M007 and M012. These are T33 worked examples.
- **Strata by `final_L1`:**
  - all SPEC_PARTIAL (4);

- **Draw:**
  - Use Python `random.Random(20261115)`, sampling each stratum in this order: SPEC, SPEC_PARTIAL, UNDECIDABLE, BOTH, IMPL.
  - Within each stratum, sort by item_id before sampling.
  - Where possible, include at least one non-scout SUT per stratum: if the draw has none, replace the last drawn item with the first non-scout item in the sorted stratum that the same RNG picks.
  - Write the script to `09_collab/logs/T36_scratch/sample.py` and its output to `sample.json` **before** any search.
- **TEST items are not sampled.** §11.4.1 exempts deterministic TEST rules.

## Procedure per item
1. **Blind as far as practical.** Your script should hide `final_L1`, `A_L1`, `B_L1` and `note` from the working sheet.
   - Derive the message, operation, observed status/field and representative exchange from the labeller sheets, adjudication CSVs and runs.
   - Do your §11.4 decision first, write it, and only then join the final label.
   - Record honestly whether you had seen an item's final label earlier, for example in T33. ⚠️ Prior exposure is likely for some items.
2. **Decide whether search is mandatory** (§11.4.1 + §12.1 Q2).
   - If it is not mandatory, record `intent_search_status=not_run` and the exempting rule.
3. **Run the search** with `/usr/bin/python3 -I -B 08_experiments/tools/intent_evidence.py …`. Use the invocation template in §11.4.1.
   - Save raw JSON, stderr and exit code under `09_collab/logs/T36_scratch/search/`.
   - Reuse is allowed only per the §11.4.1 reuse rule.
4. **Review every hit:** record disposition (accept, reject, context or unresolved), reason, and the independence checklist (a)–(e). Do a directed manual fallback (test helpers, docs, local git history) where §11.4 requires it.
5. **Label** per §11.4.3 and §12.1 Q1/Q3/Q5:
   - New same-class policy cases get `adjudication_flag=same_class_policy`.
   - Incomplete coverage → defer (`intent_search_status=incomplete`, L1 deferred).
