C12 হিসেবে `items.csv`-এর ক্রমে ৩৬টি item code করেছি। ফলাফল `codes_C12.csv`-এ: divergence_kind-এ ১৭টি DELIBERATE ও ১৯টি ACCIDENTAL; contract_specificity-তে ২২টি SPECIFIC ও ১৪টি GENERIC। confidence 3 পেয়েছে ২৫টি এবং confidence 2 পেয়েছে ১১টি item। প্রতিটি সিদ্ধান্তের implementation ও contract locator সংশ্লিষ্ট CSV row-তে আছে। এই সংখ্যা কেবল এই coding-এর বর্ণনা; কোনো সাধারণীকৃত গবেষণা-ফল নয়। সূত্র: [codes_C12.csv](codes_C12.csv), item_id U01–U36।

পদ্ধতি ছিল প্রতিটি item-এর নিজের contract ও implementation থেকে proposition-এর X ও Y আলাদাভাবে যাচাই করা। অন্য item-এর ফাইলের সঙ্গে তুলনা করিনি। প্রথম shell command ছিল `cat TASK_CODE.md`; এরপর অনুমোদিত `../../../09_collab/PROTOCOL.md` পড়েছি। Explicit serialization, enum member, response shape ও route construction-কে DELIBERATE; missing mapping, missing scope check, wrong variable এবং null handling-এর ঘাটতিকে ACCIDENTAL ধরেছি। এটি দৃশ্যমান code structure-এর classification; developer-এর মানসিক উদ্দেশ্যের দাবি নয়। নিয়মের সূত্র: [TASK_CODE.md](TASK_CODE.md), “What you code” ও “Rules”।

contract_specificity নির্ধারণে operation-এর সরাসরি annotation, route, response declaration এবং আচরণ নিয়ে dedicated prose-কে SPECIFIC ধরেছি। শুধু shared schema-র type/enum/reference বা response-list-এর silence থেকে আসা বক্তব্যকে GENERIC ধরেছি। U02 ও U25-এ description optional হওয়ার dedicated prose এবং U21-এ additions/default-এর বিস্তারিত semantics থাকায় SPECIFIC দিয়েছি, যদিও সেগুলি schema-তে লেখা। অন্যদিকে U01, U09, U15 ও U20-এর আলোচ্য restriction shared model থেকে এসেছে। সূত্র: [codes_C12.csv](codes_C12.csv), item_id U01, U02, U09, U15, U20, U21, U25।
